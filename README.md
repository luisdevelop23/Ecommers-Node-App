
# ERP - BACKEND APP
backend application, warehouse management, products, sales, publications in emmers, emails, clients and more.

### Technologies implemented:
Node JS, TypeORM, TypeScript, bcrypt, JWT, Express, cookie-parser, env-var, cors, nodemon mysql2, node-api, ts-node.

## Run Locally

Clone the project

```bash
  git clone https://github.com/luisdevelop23/ERP-Node-App.git
```

Go to the project directory

```bash
  ERP-Node-App
```

Install dependencies

```bash
  npm install
```
config you .env
```bash
# port where you want to place it
PORT= 
# user
USER=
# your password
PASSWORD=
# database name
DATABASE=
# your hosting
HOST=
# the secret word you want to implement
JWT_SECRET=
# your expiration time
JWT_EXPIRES_IN=
# production 0 development
NODE_ENV=development
```

Start the server

```bash
  npm run dev
```
